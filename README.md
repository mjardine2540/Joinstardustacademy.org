# Joinstardustacademy.org

Course video site for Stardust Academy: free and budget-friendly college courses for adult learners.

The site is a single `index.html` page published with GitHub Pages. Course videos are hosted on YouTube (public or unlisted) and embedded on the page.

## Adding a new video

1. Upload the video to the Stardust Academy YouTube channel as Public or Unlisted.
2. Copy the video ID, the part after `youtu.be/` and before any `?`.
3. In `index.html`, add an iframe using `https://www.youtube-nocookie.com/embed/VIDEO_ID`, copying the welcome video block as a template.
